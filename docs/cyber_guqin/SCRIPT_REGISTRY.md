## Registry Rules

- New workflow entry points must be manifest/config-driven and dry-run-first.
- `--execute` requires human approval and must use a reproduction sandbox when render/final outputs are involved.
- Accepted `F_FINAL_REVIEWED` is a protected baseline.
- R2 latest JSON is canonical; CSV/YAML exports are derived.
- Historical XWC/Baiya scripts can be read for design evidence but must not become default second-piece entry points.
- Production sample ingest, ML training, and Arrangement Mode require separate gates.
